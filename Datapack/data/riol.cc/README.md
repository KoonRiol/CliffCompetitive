# Riol.CC(システムデータパック)

この名前空間内のコマンドは、他のデータパックを作成するときにも流用できるように作っています。

## 動作確認済みバージョン / Verified minecraft versions

26.3

### できること

DamageAPI
- ダメージを防御力、エフェクト効果、エンチャント、カスタムステータスを考慮して計算し、与えることができます。
- また、引数を入力することによって攻撃者を設定するなど様々なダメージを与えることができます。
- 発射物や召喚物は召喚者のステータスを参照してダメージを与えることができます。
- 発射物や召喚物などの多段ヒット防止もすることができます。
- ダメージの種類に応じて、そのダメージを100倍で表示することができます。※要設定

死亡処理
- 死亡時の処理が行えます。
- ダメージの種類に応じて、様々な死亡ログを出すことができます。※要設定

カスタムエフェクト
- 様々なステータスを操作するバフ/デバフを追加することができます。
- 引数を使用することでほとんどどんな効果でも作ることができます。※特殊カスタムエフェクトを作る際はriol.assetsに効果を記入

キャッシュ処理
- Casheを使用することによってデータパックの負荷を軽減しています。
